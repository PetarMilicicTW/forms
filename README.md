Compare forms in Angular, React and Vue.

Sign up form with email, password and confirm password fields with requirements:

- Email field is required and validated
- Password field is required, disabled until valid email is entered and validated to be at least 8 characters long and include letters, numbers and special characters. When email is changed, password field is reset
- Confirm password field is required, disabled until valid password is entered and validated to equal password field. When password is changed, confirm password field is reset
- On success show toast
- On error show banner
